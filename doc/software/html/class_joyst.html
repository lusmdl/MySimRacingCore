◆ getDataRx()

pod_axis Joyst::getDataRx ( )

Adjusts the actual joystick value to the center if within a tolerance range.

This function retrieves the ADC axis data and checks if the actual value (act) falls within a defined tolerance around 50%. If so, the value is adjusted to 50.0 to ensure a centered position. If the value is outside this range, it remains unchanged. The minimum (min) and maximum (max) values are not modified.

Returns
pod_axis A structure containing the corrected or original ADC axis data.
